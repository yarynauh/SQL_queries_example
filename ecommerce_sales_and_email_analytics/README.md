## Project Overview

The goal of this project is to collect and analyze data regarding account creation dynamics and user email engagement (sends, opens, clicks). By evaluating user behavior across categories such as send intervals, account verification, and subscription status, this dataset enables cross-country activity comparison, key market identification, and detailed user segmentation.

## Objectives

* **Performance Tracking:** Analyze the dynamics of account creation and track user email activity over time.
* **Behavioral Evaluation:** Assess user behavior based on specific parameters, including send intervals, account verification, and subscription status.
* **Market Segmentation:** Compare activity metrics across different countries to identify key performing markets and segment users effectively.

## Technical Requirements

* **SQL (BigQuery):** Developed a comprehensive query using CTEs and aggregations to process and clean raw data.
* **Data Consolidation:** Merged account creation data with email interaction events to create a unified view of user behavior.
* **Advanced SQL Functions:** Utilized Window Functions to calculate global totals and rank countries based on user volume and engagement.
* **Visualization:** Created an interactive dashboard (e.g., in Tableau/Looker Studio) to visualize the processed dataset and regional trends.
